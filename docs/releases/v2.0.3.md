# V2.0.3 — Debug 與長時間紀錄介面改善

- 預設字體提高至 11pt；「設定 → 外觀」可選 100–200% 字級，立即套用並記住設定。表格、波形座標軸與圖例同步放大，小螢幕內容可捲動查看。
- 新增常駐錄製摘要：顯示目前裝置的錄製時間、成功寫入筆數、分檔數、最後寫入時間及檔案位置；等待資料、斷線重連與寫檔失敗都有明確提示。
- 可選擇並記住 CSV 儲存資料夾，全部停止錄製後即可變更。
- Log 新增搜尋、警告／錯誤篩選、暫停畫面及追蹤最新；清除畫面不刪除紀錄，暫停顯示時 CSV 仍持續寫入。
- 合併畫面刷新並重用裝置分頁，減少長時間操作的重複配置；CSV 欄位與分檔方式保留，同秒重新錄製也不覆寫舊檔。

已通過回歸測試、20 組字級／主題／視窗尺寸檢查及 10,000 筆模擬通知寫入驗證；實體 BLE／dongle 的數小時耐久與跨實體螢幕測試仍需依 README 實機確認。

下載 `PC_GIOSXTR_Demo_V2.0.3.exe`，關閉舊版後開啟新版。既有使用者可在「設定 → 關於 → 檢查更新」取得更新。
