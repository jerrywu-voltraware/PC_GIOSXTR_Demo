# V2.0.4 — 訊號比較頁、精簡波形與錯誤通知開關

- 新增 **Compare 比較頁**：在 PTU／PRU 分頁的欄位按右鍵「加入比較」，即可把不同訊號（也可跨裝置）放在同一頁對照。上方數值表顯示目前值、最小、最大、平均與游標值；下方圖表依單位自動分組、時間軸連動。比較清單會記住，下次開啟自動帶回。
- **Waveform 頁精簡改版**：多張圖依視窗高度自動分配、一次看完；去除重複標題與按鈕（收進每張圖的「⋯」選單）；所有圖共用時間軸並連動縮放；訊號改為可連續勾選的清單（上限由 5 張提高為 8 張）；Δ 游標、框選統計移到「分析工具」選單；每張圖可折疊；Δ 資訊壓成一行並優先顯示 Δ 值。
- 修正晚加入的圖或晚連線的裝置與既有曲線時間不對齊、畫面左側空白的問題。
- 新增 **錯誤通知開關**（設定 → 通知，或錯誤視窗內「不要自動彈出」）：預設仍會彈出；關閉後錯誤照常記錄，右上角顯示「⚠ N 筆錯誤」，點擊即可查看。

已通過完整回歸測試（299 項）與離屏版面檢查；實體 BLE／dongle 長時間運作仍請依 README 實機確認。

下載 `PC_GIOSXTR_Demo_V2.0.4.exe`，關閉舊版後開啟新版。既有使用者可在「設定 → 關於 → 檢查更新」取得更新。
