# Waveform 頁 UX 改善 設計規格（2026-11-12）

## 目的

使用者開很多訊號時 Waveform 頁 UX 很差（截圖：1080p 只看得到 ~1.5 張圖，要一直捲動，
上下圖無法對照同一時間點）。使用者 2026-11-12 要求實作第一批（1–3）＋第二批（4–6）。
第三批（效能：每筆封包同步重算全緩衝 min/max）**不在本次範圍**。

## 現況問題（app/windows/waveform_page.py）

- 每張圖是一張大卡片，plot 會被拉伸填滿，訊號名重複 4 次：卡片標題、plot 內標題
  （`setTitle` ~L1167/1172，「V_bus (mV) - PTU #9」）、左 Y 軸名（`setLabel("left")` ~L266）、圖例。
- 每卡一排 4 顆按鈕（儲存圖片/重設/清除標籤/移除，~L281-302）＋一行 stats。
- X 軸不連動；而且 **x = 每張圖、每台裝置各自的 `sample_index`**（`DeviceSeries.sample_index`，
  `_append_sample` ~L1080），晚加的圖從 0 起算 → 不同圖的同一 x 不是同一時刻。
- 工具列一排 13 個控制項（~L162-180）。
- `add_chart` 上限 5 張（~L256）。

## 第一批

### 1. 圖高自動分配
- 展開中的圖平分 `self.scroll.viewport()` 的可用高度（扣掉各卡片標題列等固定高度），
  每張 plot 最小 `scaled_px(150)`；總和超過才出現捲軸。
- 視窗 resize、加/移除圖、折疊/展開時重算。只有 1 張圖時填滿可用高度。

### 2. 去除重複資訊
- 移除 plot 內標題、左 Y 軸名稱（單位已在卡片標題）。
- 圖例：該圖可見 series ≤ 1 時隱藏，≥ 2（多裝置）時顯示。
- 卡片標題列一行：`[▾折疊] 訊號名(單位)   stats…   [⋯]`。stats 併入標題列（單裝置：
  `latest 41411  min 37024  max 45992  n 448`；多裝置太長時省略並以 tooltip 顯示完整內容）。
- 4 顆按鈕收進標題列右側「⋯」QToolButton 選單：儲存圖片、重設、清除標籤、移除。
- 游標/Δ 資訊行（`cursor_label`）維持：只在十字準線或 Δ 游標開啟時顯示。
- **存圖要自帶說明**：`save_chart_image` 匯出時暫時加回標題（訊號 - 裝置）與軸名，匯出後還原，
  讓 PNG 單獨拿出來仍看得懂。

### 3. X 軸連動（示波器式）
- **共用取樣計數**：改為頁面層級每台裝置一個計數器（例如 `self._device_sample_index[address]`），
  每次 `refresh_device` 收到該裝置一筆資料時 +1，所有圖用同一個 x。
  不變式：**同一裝置的同一筆 notify，在每張圖上的 x 相同**；新加的圖從「目前計數」開始，不是 0。
  斷線重連的對齊行為（現有 `_resumed_addresses` / `_align_series_to_latest` 的 NaN 斷點）保留等效語意。
  「全部重設」可把計數歸零；單張「重設」只清該圖資料，計數不動。
- 所有圖 `setXLink` 到同一基準 → 一起縮放、平移、自動捲動視窗一致（`_update_plot_window` 的範圍各圖一致）。
- 只有最下面一張「展開中」的圖顯示 X 軸刻度（與小字 "Sample"），其餘隱藏刻度文字但保留格線。
- 既有功能在連動後必須照常運作：十字準線同步（`_broadcast_crosshair`）、Δ A/B 游標、框選統計
  同步（`_on_region_changed`）、點擊標籤（markers）、暫停、歷史長度、裝置篩選（目前/全部）。
  移除圖時要解除 link，不得留下指向已刪 widget 的連結。

## 第二批

### 4. 訊號改成勾選清單
- 取代「訊號下拉 + 新增曲線」：一顆 `訊號 (n) ▾` 按鈕，彈出可**連續勾選不自動關閉**的清單
  （例如 QWidgetAction 內含 checkbox 清單），依 `SIGNAL_DEFINITIONS` 分組：PTU / PRU / Error。
- 勾選 = 新增該訊號圖；取消 = 移除該圖（與卡片「⋯ → 移除」雙向同步）。
- 上限由 5 提高為 **8**；達上限時未勾選項目 disabled，tooltip「最多 8 張圖」。
- 提供程式 API：`add_chart(field_name)`、`remove_chart(...)`、`set_signal_checked(field_name, bool)`
  （名稱可調整，但測試要用公開 API，不要戳私有屬性）。

### 5. 工具列瘦身
- 主列只留：裝置｜訊號 (n) ▾｜暫停｜十字準線｜分析工具 ▾｜歷史｜全部重設。
- 「分析工具 ▾」選單：Δ 游標 (A/B)（可勾）、清除 A/B、—、框選統計（可勾）、清除框選、—、波形設定…
- 有分析模式開啟時，按鈕文字要顯示狀態（例如 `分析工具 (Δ) ▾` / `(框選)`），避免使用者忘記模式開著。
- 盡量保留既有屬性名稱（`delta_box`、`region_box`、`delta_clear_btn`、`region_clear_btn`、
  `settings_btn`、`crosshair_box`、`pause_box`、`history_combo`、`reset_btn`）讓呼叫端/測試相容；
  改成 QAction 也可以（QAction 有 setChecked/isChecked/toggled/setEnabled），呼叫端要跟著改。

### 6. 圖可折疊
- 標題列左側 ▾/▸ 切換。折疊後只剩標題列（含 latest 值），plot 與 cursor 行隱藏。
- 折疊的圖不參與高度分配；仍持續收資料（展開時無斷點）。
- 「顯示 X 刻度的最下方圖」改為最下方「展開中」的圖。
